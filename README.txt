GitHub Pages ready

1. Put index.html and examples/ at your repository root.
2. Add images/videos to examples/.
3. Enable GitHub Pages from the main branch / root.
4. On GitHub Pages the page discovers public repository media automatically via the GitHub Contents API.

Tip: name media files with project keywords (ocr, vocr, oprs, speech, dabir, ecg, club) so the hero preview labels them with the matching system.
